A simple, fast, and responsive calculator application built with React. It helps users perform everyday calculations across multiple categories, including standard math, time conversion, temperature conversion, and unit conversions for volume, mass, and length.

## Why this project

This project was created to make daily calculations easier and more accessible. Instead of using multiple separate tools, users can do common calculations in one clean interface with a mobile-friendly design. The goal is to keep calculations straightforward, useful, and easy to navigate.

## Key Features

- Standard calculator for everyday arithmetic
- Time calculator for quick time-based conversions
- Temperature converter for Celsius, Fahrenheit, and Kelvin
- Volume, mass, and length converter
- Responsive layout for desktop, tablet, and mobile screens
- Multi-page navigation for a smooth user experience
- Clean and modern UI built with React
